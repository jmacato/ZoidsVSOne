# Zoids VS. translation glossary

Name priority: English anime dub / Zoids Wiki > Zoids Legacy translation > accurate reading of the Japanese. Zoids VS. never had an English release (Zoids: Battle Legends is the US version of Zoids VS II).

## Factions and teams
- 共和国 / 共和国軍: Republic / Republic Army
- 帝国 / 帝国軍: Empire / Imperial Army
- 共和国兵 / 一般兵: Republic Soldier / Soldier
- ゼネバス: Zenebas
- テラガイスト: Terra Geist (group trying to revive the Zenebas Empire)
- ブルーユニコン: Blue Unicorn (Republic prototype test squad)
- ロットティガー: Rottiger (Imperial special-ops squad; a squad, not a Zoid)

- ゾイドショップ: Zoid Shop; パーツリスト: Parts List
- 勝利条件 / 敗北条件: Victory Conditions / Defeat Conditions
- メモリーカード / スロットA: Memory Card / Slot A
- セーブ / ロード: Save / Load
